# 5et.uk

Company website for 5et Ltd. Target domain: [5et.uk](https://5et.uk).

## What it is

A professional multi-section company website built to satisfy Apple Developer Program enrollment requirements. Covers company identity, services, approach, corporate information, and contact details.

## Status

- **Live**: No — pending Cloudflare Pages deployment
- **Domain**: 5et.uk (registered via iCloud+, DNS managed by Cloudflare)
- **Hosting**: Cloudflare Pages (planned)

## Content

- Hero with company positioning
- About section with company background
- Services: AI Strategy, Solution Architecture, Implementation, Data Engineering, Intelligent Automation, Technical Advisory
- Approach: Discover → Design → Deliver
- Corporate information: Company number, SIC code and Companies House link
- Contact: email (m@5et.uk), LinkedIn, location

## Deployment

1. Go to [Cloudflare Dashboard](https://dash.cloudflare.com) → Pages
2. Create project → Direct Upload
3. Upload `index.html`
4. Add custom domain: `5et.uk`
5. Cloudflare auto-updates the root CNAME from `default-page.cloudflareregistrar.com` to the Pages project

## Why

Apple Developer Program rejected enrollment (case 102936700407) because the website at `5et.uk` showed Cloudflare's default parking page. Apple requires a substantive, professional website demonstrating the organisation is a real, active business.
